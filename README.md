# LinguPlay releases

Official public installer downloads for [LinguPlay](https://linguplay-2uj.pages.dev/).

This repository contains release binaries only. The application source repository
is private. Download the latest available installer from
[Releases](https://github.com/linguplay/LinguPlay-Releases/releases/latest).

## macOS

The current macOS build supports Apple Silicon. Early builds are not yet
notarized by Apple, so macOS may require Control-clicking the app and choosing
**Open** the first time.
